# vlogmi.com

The files served at vlogmi.com through GitHub Pages. This repository holds only the finished site.

Do not edit files here by hand. The site is built in the Vlogmi app repository
(`design/proposals/main-site-builds-20261109/`): run `prepare.mjs`, `build.mjs`, then
`dist.mjs <this folder>`, review, commit and push. Pushing to `main` publishes the site.

Photos and videos are the founder's own Vlogmi posts. Fonts are under the SIL Open Font License
(licence files are in `shared/fonts/`).
